Q1.

왜 MP3 변환기나 웹에 업로드하지 않고 로컬 변환을 해야 하나요?
기업 미팅이나 개인 녹취 등 민감한 데이터가 포함된 오디오 파일을 외부 해외 서버로 업로드하면 정보 유출 위험이 있습니다. 이 도구는 사용자의 웹 브라우저 내부 메모리에서 100% 로컬로 인코딩하므로 보안 걱정이 없습니다.

Q2.

API 키나 유료 결제가 필요한가요?
아닙니다. Web Audio API 및 오픈소스 LameJS 엔진을 사용하여 브라우저가 직접 계산하므로, API Key가 전혀 존재하지 않으며 평생 무료입니다.
