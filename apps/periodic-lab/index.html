📐 주기율표란?

주기율표는 118개의 원소를 원자번호 순으로 배열하되, 비슷한 화학적 성질을 가진 원소들이 같은 세로줄(족)에 오도록 설계한 표입니다. 가로줄은 '주기'라 하여 전자 껍질 수를 나타내고, 세로줄은 '족'이라 하여 최외각 전자 수를 나타냅니다.

🎵 필수 암기법: 1~20번 원소

"수헬리베 붕탄질산 플네"
수소(H) → 헬륨(He) → 리튬(Li) → 베릴륨(Be) → 붕소(B) → 탄소(C) → 질소(N) → 산소(O) → 플루오린(F) → 네온(Ne)
"나마알 규인황 염아 칼카"
나트륨(Na) → 마그네슘(Mg) → 알루미늄(Al) → 규소(Si) → 인(P) → 황(S) → 염소(Cl) → 아르곤(Ar) → 칼륨(K) → 칼슘(Ca)
